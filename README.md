---

Sachiel is a simple desktop aplication created to manage sales and products for Makai/Chaska.


**Sachiel allows the user to:**
* Manage products.
* Register sales.
* Export sales to *.xlsx* and *.pdf*
* Add product details on export.
* Import new prices and products from *.xlsx*
* Create database backups.

**IMPORTANT**: 
- Sachiel uses a local SQLite DB.
- Windows x64 required.
